У результаті виконання лабораторної роботи було освоєно роботу з реляційними базами даних у середовищі
.NET із використанням бібліотеки Entity Framework Core. Було створено інфраструктурний проєкт із моделями
бази даних, реалізовано контекст даних DbContext та налаштовано зв’язки між сутностями за допомогою Fluent API.
Також було створено та застосовано міграції для автоматичного формування структури бази даних.

У ході роботи реалізовано шаблон проєктування «Репозиторій», який забезпечує зручний та незалежний доступ до даних,
а також модернізовано асинхронний CRUD-сервіс для взаємодії з базою даних через репозиторії. Консольний застосунок 
було адаптовано для роботи зі збереженими даними, що дозволило виконувати операції створення, перегляду, редагування та видалення записів.

Отримані результати підтвердили ефективність використання Entity Framework Core для спрощення роботи з базами даних, 
автоматизації процесу створення схеми БД та реалізації принципів багатошарової архітектури застосунків.[лаб3.net.pdf](https://github.com/user-attachments/files/28444856/3.net.pdf)
