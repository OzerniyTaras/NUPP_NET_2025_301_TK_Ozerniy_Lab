У результаті виконання лабораторної роботи було розроблено вебсервер на платформі ASP.NET Core Web API 
для системи TravelAgency. На основі реалізованої в попередній лабораторній роботі бази даних було 
створено REST API, що забезпечує виконання CRUD-операцій над сутностями Ticket та Vehicle.

У ході роботи було створено контролери, моделі для передачі даних та налаштовано механізм 
впровадження залежностей(Dependency Injection) для взаємодії з сервісами та репозиторіями. 
Для доступу до даних використано асинхронний CRUD-сервіс і шаблон проєктування «Репозиторій»,
що дозволило відокремити бізнес-логіку від рівня зберігання даних.

Розроблений REST API відповідає основним принципам REST-архітектури, використовує коректні
HTTP-методи та коди відповідей. Працездатність застосунку була перевірена за допомогою Swagger, 
де успішно виконано операції створення, отримання, оновлення та видалення даних. Виконання лабораторної
роботи дозволило закріпити практичні навички розробки вебсервісів засобами ASP.NET Core, побудови багатошарової
архітектури та створення REST API для взаємодії з базою даних.
