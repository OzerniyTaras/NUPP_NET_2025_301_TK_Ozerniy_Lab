У результаті виконання лабораторної роботи було розширено REST API системи TravelAgency 
засобами ASP.NET Core Identity. До проєкту було додано механізми реєстрації, автентифікації 
та авторизації користувачів, що забезпечують безпечний доступ до ресурсів вебзастосунку.

У ході роботи створено сутність користувача на основі IdentityUser, налаштовано IdentityDbContext
та виконано інтеграцію ASP.NET Core Identity з базою даних. Реалізовано кінцеві точки реєстрації
та входу користувачів, які забезпечують отримання токенів для подальшої роботи із захищеними ресурсами API.

Також було налаштовано механізм авторизації для контролерів REST API, що дозволяє обмежувати доступ 
до окремих операцій залежно від прав користувача. Роботу застосунку перевірено за допомогою Swagger, 
де протестовано сценарії реєстрації, автентифікації та виконання запитів до захищених ресурсів.

Виконання лабораторної роботи дозволило отримати практичні навички використання ASP.NET Core Identity,
налаштування безпечної автентифікації та авторизації, роботи з токенами доступу та побудови захищених 
вебсервісів на платформі ASP.NET Core.
